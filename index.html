Panduan Deploy & Arsitektur Vercel + Supabase

Dokumentasi teknis lengkap untuk production-ready deployment ke Vercel dengan PostgreSQL database.

Frontend UI (Vercel)

Single Page Application responsive menggunakan Tailwind CSS & JavaScript modern yang dihosting di Vercel.

Backend API Routes

Next.js API Routes / Vercel Serverless Functions untuk webhook WhatsApp Baileys dan integrasi Gemini AI.

Database (Supabase)

PostgreSQL relasional untuk menyimpan data kontak, kategori, sesi chat, broadcast queue, dan knowledge base.

Skema Database SQL (Supabase / PostgreSQL)

-- 1. Tabel Kategori Peserta
CREATE TABLE categories (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    keyword_index INT UNIQUE NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. Tabel Kontak Peserta
CREATE TABLE contacts (
    id SERIAL PRIMARY KEY,
    name VARCHAR(150) NOT NULL,
    phone VARCHAR(30) UNIQUE NOT NULL,
    category_id INT REFERENCES categories(id) ON DELETE SET NULL,
    status VARCHAR(50) DEFAULT 'active', -- active, waiting_admin, admin_takeover
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 3. Tabel Pesan Chat WhatsApp
CREATE TABLE messages (
    id SERIAL PRIMARY KEY,
    contact_id INT REFERENCES contacts(id) ON DELETE CASCADE,
    sender VARCHAR(20) NOT NULL, -- 'user', 'bot', 'admin'
    message TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 4. Tabel Broadcast
CREATE TABLE broadcasts (
    id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    category_id INT REFERENCES categories(id),
    message TEXT NOT NULL,
    delay_seconds INT DEFAULT 5,
    status VARCHAR(50) DEFAULT 'scheduled', -- scheduled, sending, completed
    scheduled_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 5. Tabel AI Knowledge Base
CREATE TABLE knowledge_base (
    id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    content TEXT NOT NULL,
    category VARCHAR(100),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
